# Google Sheets Setup for Alternance Tracker

## 📋 Manual Setup Instructions

### 1. Create New Google Sheet

1. Go to https://sheets.google.com
2. Create a new spreadsheet
3. Name it: **Alternance Tracker - [Your Name]**
4. Note the Sheet ID from URL: `https://docs.google.com/spreadsheets/d/[SHEET_ID]/edit`

### 2. Create Sheets (Tabs)

Create the following sheets (tabs) with exact names:

1. **Users**
2. **Configuration**
3. **Profiles**
4. **Offers**
5. **Offer_Analyses**
6. **Applications**
7. **Documents**
8. **Messages**
9. **Events**
10. **Workflow_Locks**

### 4. Format Headers

1. Select row 1 in each sheet
2. Format > Text wrapping > Clip
3. Format > Text > Bold
4. Format > Alignment > Center
5. View > Freeze > 1 row

### 5. Configure Sharing

1. Click "Share" button (top right)
2. Change to "Anyone with the link can view" (for read-only access)
3. Or invite specific Google accounts with edit access

### 6. Get Credentials for n8n

#### Option A: OAuth2 (Recommended)
1. Go to n8n: http://localhost:5678
2. Credentials > New > Google Sheets OAuth2
3. Follow OAuth flow
4. Authorize access to Google Sheets

#### Option B: Service Account
1. Create service account in Google Cloud Console
2. Download JSON key
3. Add to n8n credentials
4. Share Sheet with service account email

### 7. Save Sheet ID

Copy your Sheet ID and save it in your n8n configuration:
- In WF0 (Configuration workflow)
- Or in n8n environment variables

## 📝 Notes

- **JSON columns**: Store complex data as JSON strings
- **Dates**: Use ISO 8601 format (YYYY-MM-DDTHH:mm:ss.sssZ)
- **Booleans**: Use "TRUE" or "FALSE" (case-sensitive)
- **Empty values**: Leave cell empty (represents NULL)
- **IDs**: Use UUIDs (generated by workflows)

## 🔒 Security

- Never commit Sheet ID to public repository
- Use environment variables or n8n credentials
- Limit sharing to necessary accounts
- Enable 2FA on your Google account
